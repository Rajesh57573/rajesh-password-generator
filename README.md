# 🔐 Random Password Generator

A responsive password generator built using HTML, CSS, and JavaScript.

### ✨ Features
- Generate random 8-character passwords.
- Includes uppercase, lowercase, numbers, and symbols.
- Copy passwords with one click.
- Responsive design for mobile, tablet, and desktop.

### 🛠️ Technologies
HTML5, CSS3, JavaScript, Google Fonts, and Font Awesome.

### 🚀 Deployment
Hosted using GitHub Pages.

### 📂 Files
- `index.html` — Structure
- `style.css` — Styling and responsiveness
- `script.js` — Password generation and copying
